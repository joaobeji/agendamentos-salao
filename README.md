# Avaliação Técnica DSIN - Sistema de Agendamentos

## 🛠️ Tecnologias Utilizadas

- **Frontend:** Next.js, React, Tailwind CSS, TypeScript
- **Backend:** Node.js, API REST
- **Banco de Dados:** SQLite (arquivo de banco incluído no projeto para facilitar a execução)

## 🚀 Instruções de Como Rodar o Projeto

### Pré-requisitos

- Node.js instalado na máquina.

### Passos para execução:

1. Clone o repositório:

   ```bash
   git clone https://github.com/joaobeji/agendamentos-salao.git
   ```

2. Instale as dependências (certifique-se de configurar e instalar tanto na pasta do backend quanto no frontend, se necessário):

   ```bash
   npm install
   ```

3. Inicie o servidor/backend e o frontend conforme a estrutura do projeto.
    ```bash 
    npm run dev
    ```
4. Acesse a aplicação no navegador através do endereço local fornecido (ex: http://localhost:3000).

## Observações sobre o Desenvolvimento

O projeto utiliza SQLite, o que significa que o banco de dados já está estruturado e incluso no repositório, dispensando instalações complexas de SGBDs externos.
